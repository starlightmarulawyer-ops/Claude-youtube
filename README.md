# 법률사무소 충녕 — 할 일 관리

사무실에서 쓰는 간단한 할 일 관리 웹페이지입니다.
서버나 데이터베이스 없이 `index.html` 파일 하나로 동작합니다.

## 할 수 있는 일

- **할 일 추가**: 입력란에 적고 ‘추가’ 버튼을 누르거나 Enter 키
- **완료 체크**: 할 일 줄을 누르면 체크되고, 다시 누르면 해제
- **삭제**: 오른쪽 × 버튼. 실수로 지웠다면 화면 아래 ‘되돌리기’를 6초 안에 누르면 복구
- **자동 저장**: 브라우저를 닫았다가 다시 열어도 목록이 그대로 남음
- **스마트폰 화면 대응**, 휴대폰·PC의 어두운 화면(다크 모드) 설정도 따라감

처음 열면 사용법을 보여 주는 ‘예시)’ 할 일 3개가 들어 있습니다. × 버튼으로 지우면 다시 나오지 않습니다.

## 여는 방법

1. 이 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
2. 내려받은 ZIP 파일의 압축을 풉니다.
3. `index.html` 파일을 더블클릭하면 크롬·엣지 같은 브라우저로 열립니다.

## 꼭 알아 두실 점

- 할 일은 **그 컴퓨터의 그 브라우저 안에만** 저장됩니다. 다른 PC, 휴대폰, 다른 직원과는 공유되지 않습니다.
- 브라우저에서 ‘인터넷 사용 기록 삭제’나 ‘쿠키 및 사이트 데이터 삭제’를 하면 할 일도 함께 지워집니다.
- 시크릿(개인정보 보호) 창에서는 창을 닫으면 목록이 사라집니다.
- 파일을 다른 폴더로 옮기거나 다른 브라우저로 열면 목록이 비어 보일 수 있습니다. 늘 같은 파일을 같은 브라우저로 열어 주세요.
- 할 일 내용은 어디로도 전송되지 않습니다. 화면 글꼴만 인터넷(Google Fonts)에서 받아오며, 인터넷이 없으면 컴퓨터 기본 글꼴로 보일 뿐 기능은 같습니다.
- 의뢰인 이름 등 개인정보나 사건 정보는 적지 마세요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 웹페이지 전부 (화면, 디자인, 동작) |
| `tests/todo.test.cjs` | 자동 테스트 |
| `package.json`, `package-lock.json` | 자동 테스트 도구 설정 |

페이지를 쓰는 데에는 `index.html`만 있으면 됩니다. 나머지는 수정할 때 기능이 깨지지 않았는지 확인하는 용도입니다.

## 자동 테스트 (개발자용)

```bash
npm install
npm test
```

실제 크롬 브라우저(Playwright)로 추가·체크·삭제·되돌리기, 브라우저를 완전히 닫았다 다시 열었을 때의 저장 유지,
휴대폰 화면(390px, 320px)에서 가로 넘침이 없는지 등 12가지 항목을 확인합니다.
